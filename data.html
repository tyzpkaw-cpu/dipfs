Data sources & licenses

The dataset covers 8,183 characters: structure class, parts with names and readings, and traditional forms. It is compiled from open sources by the Zuxia IME project. The code in this repository is MIT; the data keeps the terms of the sources below.

How it is built

  1. The Zuxia IME pipeline (generate_zuxia.py) merges the sources into zuxia.parts.tsv — one line per character: a structure code, then one column per part (part|names|keys|reading|per-name), then optional traditional forms.
  2. tools/build-data.py in this repository converts the TSV into the JSON files under data/: characters sorted by code point, split into 16 chunks, plus the reverse index parts.json.
  3. Both the TSV (data-src/zuxia.parts.tsv) and the script ship with the repository, so the JSON can be rebuilt and audited.
