Decomposition Into Parts for Sinograms

dipfs is a small, dependency-free JavaScript library that breaks Chinese characters into their component parts — with each part's name and reading, the character's structure class, and its traditional forms. It covers 8,183 characters, 1,596 distinct parts and 2,546 traditional-form mappings.

What it is

  • An ES module with no dependencies (~5 KB) — works in the browser and in Node.js 18+.
  • Structure, parts, names, readings. For 好 you get left–right, 女 (nǚ) and 子 (zi).
  • Traditional forms from the General Standard Chinese Characters table: 这 → 這, 发 → 發 髮.
  • Lazy data loading. The dataset is split into 16 chunks of 512 characters; showing one character fetches a single ~60 KB chunk.
  • Reverse lookup. charsWith('氵') returns every character that contains 氵.
  • Compiled from the dataset of the Zuxia IME, a Chinese input method where this decomposition drives the parts window and the code table.

Quick start

In the browser, import the module straight from this site:

import { decompose } from 'https://dipfs.js.org/dipfs.js';

const results = await decompose('好汉');
for (const r of results) {
  console.log(r.char, r.structure.en, r.parts.map((p) => p.glyph).join(' + '));
}
// 好 left–right 女 + 子
// 汉 left–right 氵 + 又

In Node.js, keep dipfs.js and the data/ directory together and import the file:

import { lookup, charsWith } from './dipfs.js';

await lookup('好');
// { char: '好', structure: { code: 'z', … }, parts: [ 女, 子 ], traditional: [] }

const parts = await charsWith('氵');
console.log(parts.length);          // 523
console.log(parts.includes('汉'));  // true

See the API reference for everything else.

中文说明

dipfs 是一个拆字用的 JavaScript 库：给它一个汉字，它会给出这个字的结构（左右、上下、包围、独体、其他）、 组成部件、每个部件的名称与读音，以及繁体写法。数据来自足下输入法的字表，覆盖 8183 个字、1596 个部件， 其中 2546 个字有繁体写法。库本身零依赖，浏览器和 Node.js 都能用；数据按 512 字一块分片，按需加载。

本页的演示就是直接调用这个库；接口说明见 API，数据来源与许可见 Data。
